# 数字长征沙盘

以红军长征为主题的创意互动网页（“智汇星河”赛道二 · AI 编程作品）。

**直接用浏览器打开 [`index.html`](index.html) 即可**：单个文件约 1.7 MB，图片、数据、脚本全部内联，不联网、不调用任何 AI 模型，手机和电脑都能用。

## 作品内容

| 章节 | 内容 |
| --- | --- |
| 壹 · 我的长征 | 横版互动剧情（galgame）：化身一名普通的红军小战士，从于都出发，经血战湘江、四渡赤水、飞夺泸定桥、爬雪山、过草地，到达吴起镇，尾声是 1936 年三大主力会师。人物为虚构，史料卡里的时间、地点、数字取自资料原文并附出处；11 次选择，结尾生成“我的长征精神”卡；环境声由 WebAudio 现场合成 |
| 贰 · 行军沙盘 | 滚动叙事：红旗沿路线逐站前进，电报纸带显示日期与“出发后第几天” |
| 叁 · 四渡赤水 | 时间—河岸示意图，逐步演示四次渡河 |
| 肆 · 数字里的长征 | 四路红军时间对比、中央红军人数变化、可翻面的数字卡片 |
| 伍 · 一路开会，一路转折 | 17 次会议的电报纸带，决定一栏为资料原文 |
| 陆 · 人物星河 | 人物与站点的关系图 |
| 柒 · 长征故事 | 39 篇已审核的真人真事，按专题阅读 |
| 捌 · 行军考场 | 从资料自动组卷的问答，每题给出原文与出处 |
| 玖 · 长征是宣言书 | 生成个人“行军卡” |

## 史实规则

- 史料只取自 `data/` 中的知识库资料（来自《长征路上》项目），每条资料对应一个公开网页。
- 页面上的日期、数字和会议决定写在 `src/facts.js` 中，格式为“资料 ID + 原文片段”。互动剧情的史料卡写在 `src/vn-script.js` 中。构建时程序逐条到原文中核对，找不到就中止构建。
- 互动剧情中的人物是虚构的，他们的台词是创作的。程序检查这些台词、旁白和选项里不得出现任何数字；史实只通过史料卡呈现。真实历史人物不编台词、不画像。

## 构建与检查

需要 Node.js 18 或更新版本，不需要安装依赖。

```sh
npm run build   # 从 data/、src/、assets/ 重新生成 index.html
npm test        # 资料核对 + 单文件检查；如本机装有 Playwright，再在电脑和手机两种尺寸下走查全部章节并通关互动剧情
```

## 目录

```
index.html      构建产物（作品本体）
build.mjs       构建脚本：核对史料 → 组装数据 → 输出单文件
check.mjs       回归检查
src/            页面源码：shell.html、style.css、app.js、facts.js、vn-script.js（剧本）、vn-ui.js（剧情播放器）
assets/vn/      互动剧情的背景与人物剪影（GPT 生成，已压缩为 webp）
data/           知识库资料（节点、故事、阅读引导、专题、沙盘坐标与地形图）
docs/           创作文档说明、设计文档、剧本与生图清单
```

## 使用的 AI 工具

- **Claude Code**：页面设计与编程、构建与检查脚本、剧本编写，并在无头浏览器中走查。
- **GPT 图像生成**：互动剧情的背景和人物剪影。提示词见 `docs/赛道二-galgame剧本与生图清单.md`。
